# Симулятор камня — рефакторинг

## Что изменено по заданию

1. Код разделён на модули: настройки, игровая логика, Three.js-отрисовка, интерфейс и точка входа.
2. Добавлены/сохранены поясняющие комментарии и JSDoc для основных классов, методов и данных.
3. Логика Three.js вынесена в `src/renderer.js` и класс `ThreeSceneRenderer`.
4. Управление интерфейсом находится в `src/interface.js` и не содержит правил игровой механики.
5. Стили вынесены из HTML в отдельный `styles.css`.

## Структура

- `index.html` — разметка игры.
- `styles.css` — оформление.
- `src/config.js` — направления, типы рядов, причины завершения и настройки.
- `src/game.js` — класс `RockGame`, игровая механика.
- `src/renderer.js` — класс `ThreeSceneRenderer`, работа с Three.js.
- `src/interface.js` — класс `GameInterface`, кнопки и ввод.
- `src/main.js` — связывает все части приложения.

## Как запустить

Так как используются JavaScript ES-модули, открывайте игру через локальный веб-сервер, а не двойным нажатием на HTML.

Например, в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Для работы нужен доступ к CDN Three.js.

## Git-ветка

Я не могу создать ветку непосредственно в вашем GitHub-репозитории без доступа к нему. В локальном репозитории выполните:

```bash
git switch -c refactor/separate-game-modules
```

Затем добавьте файлы, проверьте их и создайте коммит:

```bash
git add index.html styles.css src README.md
git commit -m "Refactor game into separate modules"
```
