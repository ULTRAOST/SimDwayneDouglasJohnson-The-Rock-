# Симулятор камня — рефакторинг

## Структура
- `index.html` — разметка страницы и подключение файлов.
- `css/styles.css` — оформление и расположение элементов интерфейса.
- `js/constants.js` — строковые значения, цвета и настройки игры.
- `js/storage.js` — чтение и сохранение рекорда.
- `js/game.js` — игровая логика, управление, генерация дороги и проверка столкновений.

Код содержит комментарии на русском и английском языках. Переменные, функции и важные поля данных описаны рядом с объявлением.

Не перемещать файлы по отдельности: пути между HTML, CSS и JS рассчитаны на эту структуру.
